## What is this?

This is a CPU, designed specifically for learning RISC-V architecture. The core principle is to keep circuit as simple and understandable as possible. This CPU may be less perfomant then most analogues but it's purpose is to show a simple implementation of a basic RISC-V concepts, while perfomance is considered secondary.


## Why?

While good RISC-V documentation and various open-source CPU implementations exist, finding a beginner-friendly model that illustrates fundamental design trade-offs and architecture choices remains difficult. This project was created to fill that gap with clear visual aids for learners.
